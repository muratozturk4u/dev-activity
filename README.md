# dev-activity

Yerel git geçmişinden üretilen anonim geliştirici aktivite özeti.
Sadece toplu sayılar içerir — depo adı, proje detayı, commit mesajı veya kod yoktur.
İşin büyük bölümü gizli depolarda olduğu için buradaki rakamlar hiçbir yerdeki
profil grafiğiyle örtüşmez.

`activity.json` her gün otomatik güncellenir.
